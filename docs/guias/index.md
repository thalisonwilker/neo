# Guias Práticos

Guias orientados a objetivos para acelerar o uso do Neo no dia a dia e em automações:

---

## 1. [Uso em CI com `--json` e `jq`](ci-json.md)
Aprenda a integrar o Neo em pipelines de integração contínua (GitHub Actions, GitLab CI, Bitbucket Pipelines) utilizando códigos de saída semânticos, autenticação por variáveis de ambiente e filtros precisos com `jq`.

## 2. [Trocar de Provedor (GitHub ↔ Bitbucket)](trocar-provedor.md)
Passo a passo para alternar o provedor Git padrão, selecionar workspaces e operar em repositórios remotos de ambos os serviços sem conflito de credenciais.

## 3. [Fluxo Diário: Tasks → Branch → Commit](fluxo-diario.md)
O roteiro ideal para um dia produtivo de desenvolvimento: inspecione sua sprint com `neo tasks resume`, analise a demanda com `neo tasks analyze`, crie a branch recomendada e comite com padrões semânticos.
